# 当前海洋 / 货轮效果基准

## 复现入口

`assets/starter` 保存当前源文件与 lockfile，不依赖原工作区路径、Downloads 文件或预先安装的 node_modules。Node.js 使用项目 README 中的版本要求。启动后货轮入口 `/?scene=cargo`，海洋入口 `/?scene=ocean`。

默认主体名称 HORIZON；截图里“星辰远航号”是 QA 时通过界面输入的名称，浏览器已有名称会覆盖默认值。复现截图时通过 UI 应用该名称，而非修改生成器的通用默认。

## 可见与交互能力

- 约 150 米货轮由几何生成，含容器、驾驶台、栏杆、天线、导航标识及独立运动零件。
- 目标航速、实际速度平滑变化、平滑航向、海里航程；拖船与浮标 / 木桶。
- 自由环绕、驾驶台、俯视、左舷、日月观测；空白拖动旋转、右键平移、滚轮缩放。
- 默认落日 17.6（17:36），振幅 1.2m、风速 7m/s、锐度 0.55。默认机位局部偏移 [65,27,200] 随船向旋转；船首可朝日月。
- 八组 Gerstner 波谱，顶点位移、CPU 浮力采样、逐像素短波法线及远处 band limit；反射、高光、压缩浪峰白沫。
- 航迹按移动距离取样，世界坐标历史保留；几何泡沫、船艏粒子及浮点渲染目标支持下的局部二维扰动。
- 理想日月轨道、自定义日出 / 日落、晴 / 阴 / 雾 / 雨、波浪 / 风速 / 锐度、暂停与截图。
- 中文船名更新船体、容器标识、界面及导出字幕，按场景在浏览器保存。
- 手动 GPU canvas 录屏；45 / 90 秒自动演示，720p / 1080p、可选合成环境音、预览 / 下载。
- 自动导出固定 30fps，恢复原参数、位置、相机和暂停状态；新模拟器要重做对应章节。

## 不应继承的夸大结论

该项目独立实现了参考风格，没有确认拿到 Fazley 的原项目源码。船体起伏是采样近似，不是完整六自由度水动力；高度场不是三维流体；日月不是真实天文历；环境音不是定位空间音频。

实测完整 45 秒视频轨 1350 帧、30/1fps、H.264，AAC 音轨有约 0.013 秒编码尾部填充。实时预览与手动捕获帧率曾明显随浏览器可见性变化，不能复述为“已达到稳定实时 30 / 60fps”。
